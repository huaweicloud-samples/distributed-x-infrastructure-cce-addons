# 架构说明

## 整体架构

```
┌────────────────────────────────────────────────────────────────────┐
│                      Git 仓库 (OBS / CodeHub)                      │
│                     存放 Helm Charts 配置文件                      │
└──────────────────────────────────┬─────────────────────────────────┘
                                   │ Pull
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                        ArgoCD (App of Apps)                        │
│                       声明式 GitOps 持续交付                       │
└──────────────────────────────────┬─────────────────────────────────┘
                                   │ Sync
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                            Helm Charts                             │
│                         Add-ons 包管理工具                         │
└───────┬─────────────────┬─────────────────┬─────────────────┬──────┘
        │                 │                 │                 │
        ▼                 ▼                 ▼                 ▼
┌──────────────┐  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│   监控组件   │  │   日志组件   │  │   网络组件   │  │   运维组件   │
│Prometheus   │  │Fluent Bit   │  │ELB Ingress  │  │metrics-server│
│   Grafana   │  │   + LTS     │  │cert-manager │  │              │
└───────┴─────┴────────┬───────┴────────┬───────┴─────┴───────┘
                       │                │              │
                       └────────┬───────┴──────────────┘
                                │
                                ▼
┌────────────────────────────────────────────────────────────────────┐
│                          Huawei CCE 集群                           │
│                    Kubernetes 容器引擎托管服务                     │
└────────────────────────────────────────────────────────────────────┘
```

## 1. GitOps 层

- **ArgoCD**：声明式、GitOps 持续交付工具
- **App of Apps 模式**：根应用管理子应用

## 2. 包管理层

- **Helm Charts**：Kubernetes 包管理
- **公共 Chart 仓库**：Prometheus、Grafana 等

## 3. Add-ons 层

| 类别 | Add-on | 说明 |
|------|--------|------|
| 监控 | Prometheus | 指标收集 |
| 可视化 | Grafana | 仪表盘 |
| 日志 | Fluent Bit | 日志收集 |
| 网络 | ELB Ingress | 负载均衡 |
| 安全 | cert-manager | 证书管理 |

## 技术栈

| 组件 | 华为云服务 |
|------|-----------|
| 容器编排 | CCE |
| GitOps | ArgoCD |
| 包管理 | Helm |
| 监控 | Prometheus + Grafana |
| 日志 | Fluent Bit + LTS |
| 网络 | ELB |
